Text Format Guide

Enter questions in this format, separated by blank lines. All formatting is preserved exactly.

Q: If log₂ = 0.3010, find log₂₀
A: 1.3010
B: 1.6020
C: 2.3010
D: 2.6020
Correct: A
Solution: log₂₀ = log₂(4×5) = log₂4 + log₂5
          = 2 + 0.3010 = 1.3010
Subject: mathematics
Exam Type: JAMB
Time Limit: 90

Q: Solve for x: 2x² - 5x + 3 = 0
A: x = 1, x = 1.5
B: x = 1, x = 2
C: x = 0.5, x = 3
D: x = 2, x = 3
Correct: A
Solution: Using quadratic formula:
          x = [5 ± √(25 - 24)] / 4
          = [5 ± 1] / 4
          = 1 or 1.5
Subject: mathematics
Exam Type: WAEC/NECO
Time Limit: 120
